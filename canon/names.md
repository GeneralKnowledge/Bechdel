# Names

**Rule:** one handle, one person. A handle is the name the narration uses for someone; "Also on the page" lists the other names the text uses for her. Before a new person gets a name, check this file. `python3 tools/names_check.py` fails if any name appears twice and lists pairs close enough to confuse a reader.

The **Near** column records known near-clashes and what is done about them. It is kept by hand: the script prints near pairs as warnings but does not read or check this column. On 15 Nov Reuben renamed three people to remove near-clashes ([PLAN_FINDINGS.md](../docs/PLAN_FINDINGS.md) items 1 to 3): Merrit is now **Ada**, Perpetua Vane is **Perpetua Gaunt**, Win Haskett is **Win Corley**. Those three names are retired.

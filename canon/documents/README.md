# Documents

The exact wording of in-world documents whose words are clues: a diary line, a tribunal formula, a letter, a hymn verse. They may be drafted before the prose (see [docs/WORKING_GUIDE.md](../../docs/WORKING_GUIDE.md)) and are canon once written. One file per document, named by date and source, for example `0646_marit_diary_winter.md`. No document longer than a page.
